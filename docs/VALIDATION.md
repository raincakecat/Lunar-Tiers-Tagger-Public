# Validation

The project includes Node API tests, Java tests, and Fabric client game tests for each supported version. These cover rank selection, restrictions, cache behavior, public response fields, player profiles, and key bindings. Run the checks listed in the README.

All three versions passed local world tests. The 26.3 Windows test encountered an intermittent native Java startup crash and passed with test-only diagnostic JVM options. Full Linux world testing and broader multiplayer rehearsal remain pending.
