# Release status

The client and rank API are an implementation candidate. Builds are provided for Minecraft 1.21.11, 26.2 and 26.3. The settings and nearby-player profile have been tested in local Minecraft worlds. Wider multiplayer testing remains pending.

A 26.3 test on Windows encountered a native Java startup crash and passed with diagnostic JVM options; the cause is unresolved. Full Linux world tests remain unverified. See VALIDATION.md.
